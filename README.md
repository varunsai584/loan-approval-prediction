### Loan Approval Prediction

# Overview
This project predicts loan approval using machine learning models based on applicant financial and demographic data.

# Tech Stack
- Python
- Pandas
- Scikit-learn
- Matplotlib

# Handled missing values using forward fill
- Encoded categorical features using Label Encoding
- Trained multiple models:
  - Logistic Regression
  - Decision Tree
  - Random Forest
- Compared model performance using accuracy and classification metrics

# Results
- Achieved ~75–85% accuracy depending on model
- Random Forest performed best due to better handling of non-linear data

# Output
- Printed classification report
- Visualized model comparison using bar chart

# How to Run
pip install -r requirements.txt  
python train_model.py
